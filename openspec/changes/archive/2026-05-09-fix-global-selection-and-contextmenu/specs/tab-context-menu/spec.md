## MODIFIED Requirements

### Requirement: 标签右键菜单与标签栏空白区域菜单共存
标签栏 SHALL 区分"标签上右键"和"空白处右键"两种情况，分别显示不同的右键菜单。

#### Scenario: 在已有标签上右键
- **WHEN** 用户在某个标签页标签上右键点击
- **THEN** 弹出标签管理菜单（关闭/关闭其他/关闭全部/关闭左侧/关闭右侧）
- **THEN** 事件不冒泡到标签栏空白处或全局 handler

#### Scenario: 在标签栏空白处右键
- **WHEN** 用户在标签栏没有标签覆盖的空白区域右键点击
- **THEN** 弹出标签栏空白处菜单（新建文件/打开文件/打开最近文件）
- **THEN** 不弹出标签管理菜单

#### Scenario: 标签右键事件隔离
- **WHEN** 用户在标签上右键点击
- **THEN** 标签右键菜单正常显示
- **THEN** 标签栏空白处的 contextmenu handler 不被触发
